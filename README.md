FDE 捏脸助手 —— 使用说明
作者：ckjj    
==================================================

【怎么用】
  1. 把整个文件夹解压到任意位置（路径不要用特殊符号）
  2. 双击「launcher.py」
  3. 进入界面后，点「选择图片」挑一张正脸照片
  4. 点「开始生成」，人物卡会自动保存到 output 文件夹
  不设充值

【不需要装任何东西】
  本压缩包自带运行环境，不用安装 Python、不用装显卡驱动、
  不需要联网下载额外组件。解压就能用。

【对照片的要求】
  · 单人正脸，五官清晰
  · 多人合照、侧脸、遮挡严重会提示失败
  · 支持 jpg / png / bmp / webp

【生成结果】
  output 文件夹里的 *_character.png 就是人物卡，
  直接在游戏里打开使用即可。
  仅支持 AI 少女 / Honey Select 2，建议用于女性角色。

【常见问题】
  软件显示"未连接到云端服务"
      -> 检查网络；服务端可能正在维护，稍后再试
  提示"访客免费试用 3 次已用完"
      -> 点右上角「登录 / 注册」，注册后每天 6 次
  提示"没有检测到人脸" / "检测到多张人脸"
      -> 换一张单人正脸照片
